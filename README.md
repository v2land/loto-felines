# Loto 10/49 — Félines M15 B

Pages de la campagne de financement de l'équipe de hockey Félines M15 B (saison 26-27).

| Page | Pour qui | Rôle |
|---|---|---|
| `index.html` | Tout le monde | Accueil avec deux boutons |
| `amis.html` | Amis de la joueuse | Choisir ses séries et copier le message à envoyer à la joueuse |
| `parent.html` | Parent de la joueuse | Inscrire ou coller les séries, puis télécharger la feuille Excel pour Isabelle |
| `admin.html` | Isabelle seulement | Importer les 18 feuilles, entrer les tirages, voir le classement et le(s) gagnant(s) |

Aucune donnée n'est envoyée sur Internet : les séries du parent restent dans son navigateur.

## Mettre en ligne avec GitHub Pages

1. Sur github.com, crée un dépôt **public** nommé `loto-felines`.
2. Clique **Add file → Upload files**, glisse les 5 fichiers (`index.html`, `amis.html`, `parent.html`, `admin.html`, `README.md`), puis **Commit changes**.
3. Va dans **Settings → Pages**.
4. Sous **Build and deployment**, choisis **Deploy from a branch**, la branche **main** et le dossier **/ (root)**, puis **Save**.
5. Attends 1 à 2 minutes, puis rafraîchis la page : l'adresse du site s'affiche en haut.

## Faire une correction

Clique sur le fichier dans le dépôt, puis sur l'icône crayon (ou remplace-le avec **Add file → Upload files**), et **Commit changes**. Le site se met à jour en 1 à 2 minutes. Les liens ne changent pas et les séries des parents restent dans leur navigateur.

## Confidentialité

Chaque page contient une balise `noindex` pour que les moteurs de recherche ne l'affichent pas. Ne publie pas les liens sur Facebook ni sur d'autres sites : l'équipe n'a pas de permis de la Régie des alcools, des courses et des jeux.
